# 🤖 AI Virtual Assistant

A Python-based AI Virtual Assistant with a modern CustomTkinter GUI.

## ✨ Features

- 🤖 AI Chat
- 💬 Graphical Chat Interface
- 🎤 Voice Input
- 🔊 Voice Response
- 🔐 User Login & Registration
- 📝 Notes Management
- ⏰ Reminders
- 🌦️ Weather Information
- 💻 PC Automation
- 🔎 Google Search
- 💾 SQLite Database
- ⚙️ Application Settings

## 🛠️ Technologies

- Python 3.13
- CustomTkinter
- SpeechRecognition
- PyAudio
- pyttsx3
- SQLite
- Open-Meteo Weather API
