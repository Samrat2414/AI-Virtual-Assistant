# 🤖 AI Virtual Assistant

A Python-based AI Virtual Assistant with a modern graphical user interface, voice recognition, and text-to-speech capabilities.

## ✨ Features

* 🎙️ Voice Recognition
* 🔊 Text-to-Speech
* 🖥️ Modern GUI using CustomTkinter
* 🎤 Microphone Support
* ⚡ Fast and Simple Interface
* 🐍 Built with Python

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Samrat2414/AI-Virtual-Assistant.git
cd AI-Virtual-Assistant
```

### 2. Install Dependencies

Python 3.13 is recommended for this project.

```bash
py -3.13 -m pip install -r requirements.txt
```

### 3. Run the Project

```bash
py -3.13 main.py
```

## 📦 Requirements

The project uses the following Python packages:

* CustomTkinter
* SpeechRecognition
* PyAudio
* pyttsx3

All required packages can be installed using:

```bash
py -3.13 -m pip install -r requirements.txt
```

## 🖥️ Usage

1. Clone the repository.
2. Install the required dependencies.
3. Connect a working microphone.
4. Run `main.py`.
5. Use the GUI to interact with the AI Virtual Assistant.
