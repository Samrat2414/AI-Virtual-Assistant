# 🤖 AI Virtual Assistant

A Python-based AI Virtual Assistant with a modern graphical user interface, voice recognition, and text-to-speech capabilities.

## ✨ Features

- 🤖 AI Chat
- 🎙️ Voice Recognition
- 🔊 Text-to-Speech
- 🖥️ Modern CustomTkinter GUI
- 🌦️ Weather Information
- 📝 Notes
- ⏰ Reminders
- ⚙️ Settings
- 🔐 User Login
- 💻 Desktop Automation

## 🛠️ Technologies

- Python
- CustomTkinter
- SpeechRecognition
- PyAudio
- pyttsx3
